## 2. 分功能详述

### FUN-003: 故障预警引擎

- **功能目的**：实时分析设备运行参数，提前 ≥ 48h 检测异常模式并发出预警
- **来源功能**：FEA-003
- **来源故事**：ST-003, ST-008
- **前置条件**：设备数据已接入（FUN-001），传感器数据质量验证通过
- **角色与权限**：设备维修技师（查看预警+执行建议）、设备主管（管理预警+生成工单）、IT 周工（标记误报+调整基线）

#### 主流程

```text
1. 数据采集层持续推送设备运行参数（温度/振动/压力/电流）到预警引擎
2. 引擎按基线模型比对当前参数
3. 检测到偏离 → 计算偏离程度和趋势 → 判定故障概率和预计发生时间
4. 故障概率 ≥ 阈值 → 触发预警
5. 推送预警通知给维修技师和设备主管
6. 技师查看预警详情（异常参数/趋势图/建议操作/所需备件）
7. 主管评估后决定：生成工单 或 标记误报
```
