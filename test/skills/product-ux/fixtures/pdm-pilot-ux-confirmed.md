## 3. UX 流程与交互规则

### 3.1 主流程（P0）：设备监控→预警→工单→维修闭环

```mermaid
graph TD
    A[设备数据采集] --> B[实时监控看板]
    B --> C{异常检测}
    C -->|正常| B
    C -->|异常| D[故障预警通知]
    D --> E{是否误报?}
    E -->|是| F[IT检查数据质量]
    F --> B
    E -->|否| G[生成维护工单]
    G --> H[指派维修技师]
    H --> I[技师手机端接单]
    I --> J[执行维修+扫码记录]
    J --> K[工单关闭]
    K --> L[备件消耗记录]
    L --> M[试点效果评估]
```

### 3.2 分支与状态

```text
实时监控看板状态:
  - 正常（绿色）: 参数在基线范围内
  - 关注（黄色）: 参数偏离基线但未触发预警阈值
  - 异常（红色）: 触发预警，需立即处理

预警处理分支:
  - 正常路径: 检测→预警→工单→维修→关闭
  - 误报路径: 检测→预警→IT确认误报→标记→反馈模型
  - 升级路径: 高严重度预警→通知工厂厂长→协调生产计划
```
