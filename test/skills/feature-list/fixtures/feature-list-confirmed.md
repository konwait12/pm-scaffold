## 3. 分功能详述（关键 FEA）

### FEA-001 职位搜索（详述）
- 入口：首页搜索框 / 高级搜索页
- 搜索维度：城市（多选）/ 行业（多选）/ 经验范围（0-1/1-3/3-5/5+ 年）
- 结果排序：相关性 / 最新 / 薪酬
- 分页：每页 20 条
- 性能：P99 < 800ms（10 万职位规模）

### FEA-006 HR 后台简历池（详述）
- 入口：HR 登录后默认页
- 筛选维度：职位 / 状态（待审/面试/录用/拒绝）/ 标签 / 投递时间
- 单条操作：查看简历 / 标记状态 / 添加标签 / 拒绝（带原因）/ 安排面试
- 批量操作：批量拒绝 / 批量标签

### FEA-012 招聘漏斗（详述）
- 漏斗阶段：曝光 → 点击 → 投递 → HR 查看 → 面试 → 录用
- 每阶段转化率 + 同比环比
- 维度筛选：按职位 / 渠道 / 时间 / HR
