## 2. 移动端特殊规则

- **IX-002 mobile**：spinner 居中而非按钮内（小屏幕空间）
- **IX-005 mobile**：空状态插画 + 大按钮（>44px tap target）
- **IX-021 mobile**：禁用按钮颜色降低对比度（不误触）
- **IX-035 mobile**：黄条固定底部而非顶部（不挡内容）

## 3. 跨状态转换

```
loading → success: 200ms 后展示结果
loading → error: 超时/失败 → error 状态
empty → success: 用户操作（如搜索）→ 结果
success → empty: 搜索结果被清空（如筛选过严）
error → retry: 用户点重试 → loading → success/error
disabled → enabled: 条件满足（如简历解析完成）
```

## 5. 可访问性交互补充（AODA）

### 5.1 键盘导航
- **IX-036**：所有可点击元素必须可 Tab 聚焦 → Tab 顺序按视觉流从上到下
- **IX-037**：Enter 触发按钮点击（与点击等效）
- **IX-038**：Esc 关闭模态框/下拉框 → 回到触发前焦点
- **IX-039**：Space 按下触发按钮 → 松开完成点击（符合 WCAG 标准）

### 5.2 屏幕阅读器（Screen Reader）
- **IX-040**：所有图标必须有 `aria-label` 描述，如"收藏此职位"
- **IX-041**：加载骨架屏必须标注 `aria-busy="true"`
- **IX-042**：错误提示必须 `role="alert"` → 屏幕阅读器立即播报
- **IX-043**：禁用按钮必须 `aria-disabled="true"`

### 5.3 对比度与字体
- **IX-044**：文字与背景对比度 ≥ 4.5:1（WCAG AA 级）
- **IX-045**：大文本 ≥ 3:1（18pt+）
- **IX-046**：最低字号 ≥ 14px（正文），不允许更小
- **IX-047**：用户缩放 200% 不丢失内容，不出现横向滚动条

### 5.4 触摸目标大小
- **IX-048**：所有可点击触摸目标 ≥ 44×44px（WCAG 要求）
- **IX-049**：邻接可点击元素之间间距 ≥ 8px（防误触）

## 6. 设计系统对齐

| 设计系统组件 | IX 特殊规则 |
|---|---|
| 按钮 | 三种状态（default/hover/disabled）透明度严格遵循设计 token |
| 输入框 | 聚焦时外发光，错误时下红框 → 交互设计师规定 |
| 下拉框 | 移动端滚动锁定背景，避免两层滚动 |
| 模态框 | 点击遮罩关闭，支持 Esc → 设计师统一规范 |
| toast | 3s 后自动消失，不阻操作，可手动关闭 |
