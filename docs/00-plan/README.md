# PRD 脚手架计划库

本目录只保存当前有效的规划规范。脚手架服务于一件事：把原始业务需求转化为经人工确认的 `prd.md`。

## 阅读顺序

1. [00-项目总纲与分层标准.md](./00-项目总纲与分层标准.md)：先理解五层结构和权威边界。
2. [01-三阶段主流程与工作事项.md](./01-三阶段主流程与工作事项.md)：查看三阶段、五个工作事项，以及 §5 的十类正式产出物和依赖关系。
3. [02-共享机制与产物契约.md](./02-共享机制与产物契约.md)：查看所有 Skill 复用的控制规则。
4. [03-实施迁移与验证计划.md](./03-实施迁移与验证计划.md)：查看实施状态、兼容策略和验收方法。

`references/` 仅用于方法论和可视化参考；`_archive/` 只保存历史版本。二者都不定义当前流程。

旧版独立产出物清单已移入 `references/旧产出物清单_非权威.md`。当前正式产出物及关系只以 `01-三阶段主流程与工作事项.md` §5 和注册表为准。

## 权威边界

- 产品目标、阶段划分、工作事项和产出边界：以本计划库四篇规范为准。
- AI 运行时规则和机器接口：以 `src/framework/` 为准。
- Skill 实际行为：以对应 `SKILL.md` 为准，但不得违反前两项。
- 发生冲突时停止执行并修正规范，不允许用“优先级覆盖”掩盖不一致。
