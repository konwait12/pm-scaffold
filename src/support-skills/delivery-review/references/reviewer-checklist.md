# 人工评审清单：交付评审包

由业务负责人或产品负责人逐项回答“是 / 否 / 不适用”。任一阻断项为“否”时退回修订。

- [ ] 结论是否直接说明当前能否进入人工决定？
- [ ] 每个需求命题是否只有一个可判断结果，并明确范围外内容？
- [ ] 每个命题是否有来源、知识状态和可复现验收？
- [ ] 是否区分了确认事实、人工决定、假设、AI 推断和未知？
- [ ] 是否检查了正常路径、边界输入、失败路径和回退条件？
- [ ] 是否存在新增但未被上游确认的范围、数字或阈值？
- [ ] 每个未决项是否有 owner、下一步和阻断性？
- [ ] 评审包是否停在 `ready_for_human_review`，没有伪造 `confirmed`？
- [ ] 决定是否记录了授权人、时间和意见，并可追溯到 ReviewRecord？
