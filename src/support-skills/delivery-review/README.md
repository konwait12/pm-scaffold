# 交付评审

交付评审是一个过程型内部能力，用于把已有需求或 PRD 草稿整理成可供人工决策的评审包。它吸收 Superpowers 的三个有用做法：先写完成条件、用行为证据验证、交付前进行独立复核。

它不产生新的业务事实，不替代主干 Skill，也不自动确认产物。输出应放在 REQ 的 `99-review/support/delivery-review.md`，最高状态为 `ready_for_human_review`。

使用顺序：读取 `SKILL.md` → 按 `references/output-contract.md` 记录 → 用 `references/reviewer-checklist.md` 自检 → 交业务负责人或产品负责人确认。
