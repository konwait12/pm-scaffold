# 支持能力

按需触发的条件能力。有独立的触发条件、输入输出和人工责任人，但不占主干阶段。

| 目录 | 能力 | 触发条件 |
|---|---|---|
| `competitive-research/` | 竞品调研 | 业务方案不清或功能设计缺乏参考时 |
| `solution-assessment/` | 方案评估 | 已存在具体产品方案，且可行性或多方案取舍会影响范围、成本或风险时 |
| `prd-publish/` | PRD 发布 | PRD confirmed 后导出飞书/PDF/HTML + 通知审批 |

与共享机制的区别：支持能力有独立的业务价值和人工决策责任；共享机制是纯控制能力。
