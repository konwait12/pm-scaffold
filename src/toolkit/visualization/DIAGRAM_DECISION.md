# Diagram Selection

Diagram selection is a toolkit decision, not a global mandatory gate.

Use a diagram when the artifact contract requires one or when reviewers need a visual representation. Choose the lightest useful format:

- Mermaid for authoritative flow logic embedded in Markdown.
- FigJam/whiteboard for collaborative editing.
- HTML prototype for UX communication.
- PNG/SVG only for distribution where editable formats are unavailable.

Every visual derives from the same source table or stable IDs, is checked for rendering, and is linked from the artifact. A diagram never replaces required text, rules or human confirmation.
