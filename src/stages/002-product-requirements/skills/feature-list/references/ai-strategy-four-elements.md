# AI 策略四要素技法参考（AI Strategy Four Elements）

> 本文将相关实践转化为本项目的可选方法，不引入外部运行时依赖。
> 定位：feature-list 产出的 FEA-XXX 功能清单文本是权威；本文档提供"把智能化功能按四要素结构化 + 按策略模式描述"的技法，增强策略逻辑与兜底可见性。
> 触发：当功能涉及推荐/排序/召回/意图识别/审核/个性化/动态定价等 AI 策略时使用。**按需加载，不设全局闸门**。

| 外部 skill 输入 | pm-scaffold 对应产物 | 说明 |

## 2. AI 策略四要素（吸收自 prd-writer）

每个 AI 功能（FEA-XXX）拆解为：

| 要素 | 内容 | 必填 |
|---|---|---|
| **输入信号** | 策略依赖的输入数据（用户行为/属性/上下文/历史/画像） | ✅ |
| **模型/策略逻辑** | 推荐算法/排序规则/召回策略/意图分类逻辑（描述层面，不写代码） | ✅ |
| **输出形式** | 策略产出（列表/排序/标签/分数）与展示位置 | ✅ |
| **兜底规则** | 策略失效/冷启动/异常时的降级方案（追溯 BR-XXX） | ✅ |

## 3. 六种 AI 策略模式（吸收自 prd-writer strategy-patterns，按 FEA 类型选用）

### 3.1 推荐系统策略
- 标准三层架构：召回层 → 粗排层 → 精排层 → 重排/业务规则
- 描述要点：召回源（协同过滤/内容相似/热门/关注关系）、排序目标（CTR/时长/转化/多目标加权）、业务约束（去重/打散/品类均衡/广告位）、冷启动（新用户用人口属性/热门兜底，新内容用质量分）

### 3.2 搜索策略
- 描述要点：查询理解（分词/纠错/意图识别/Query 改写）、召回（倒排索引/向量检索/混合）、排序（相关性×质量分×个性化）、兜底（无结果降级展示）

### 3.3 意图识别策略
- 描述要点：意图分类体系（树形）、置信度阈值（高置信直接执行/低置信澄清确认）、多意图处理、兜底（未识别转人工/通用回复）

### 3.4 内容审核策略
- 描述要点：审核维度（违规类型体系）、处置策略（机审→人审→申诉）、分级处置（不展示/限流/警告/封号）、误伤率控制目标

### 3.5 个性化策略
- 描述要点：用户画像（兴趣标签/行为序列/人口属性）、个性化程度（全个性化/混合/纯热门）、隐私合规（数据使用说明，用户可退出）

### 3.6 定价/激励策略（to B 常见）
- 描述要点：触发条件（用户行为/时间窗口/库存状态）、激励力度（金额范围/发放规则）、防滥用（频率限制/用户分层）、效果衡量（增量 ROI 而非绝对 GMV）

## 4. 通用策略 PRD Checklist（吸收自 prd-writer）

- [ ] 明确策略优化目标（单一核心指标）
- [ ] 列出输入信号及数据来源
- [ ] 描述策略逻辑（伪代码或流程图，非真实代码）
- [ ] 定义兜底规则（策略不可用时的降级）
- [ ] 设计 A/B 实验方案
- [ ] 说明冷启动处理
- [ ] 列出数据/隐私合规要求

## 5. 工作流程

1. **识 AI 功能**：从 FEA-XXX 标注涉及 AI 策略的功能。
2. **选策略模式**：按 §3 六种模式匹配（推荐/搜索/意图识别/审核/个性化/定价）。
3. **拆四要素**：按 §2 输入/逻辑/输出/兜底填充；冷启动须单独说明。
4. **挂兜底**：兜底规则追溯 BR-XXX；无规则标 `待确认`。
5. **挂数据**：输入信号字段追溯 VL-XXX；输出度量挂 tracking-plan；优化目标挂 BG-XXX 北极星。
6. **跑 checklist**：按 §4 通用 checklist 自检。

## 6. 核心硬规则

1. **策略逻辑描述不写代码**：四要素停在"策略说明"层面，不写算法实现/模型架构/训练数据（超出 PRD-only）。
2. **兜底必填**：每个 AI 功能必须列降级方案，追溯 BR-XXX；无兜底标 `待确认`。
3. **冷启动显式**：策略须说明冷启动（无历史数据）的处理，不默认可用。
4. **to B 可解释**：to B 智能化策略须标注可解释性要求（如审批需说明推荐理由、定价需说明计价依据）。
5. **优化目标单一且量化**：策略优化目标须为单一核心指标且可量化，追溯 BG-XXX 北极星。
6. **隐私合规**：个性化/审核策略须列出数据/隐私合规要求（to B 含数据出境/审计）。

## 7. 边界（Do Not）

- 不写算法实现/模型架构/训练数据/特征工程（超出 PRD-only）。
- 不替代 FEA-XXX 文本——四要素是结构化增强。
- 不替业务方定策略阈值——交人工确认，标 `AI_INFERENCE`。
- 不承诺模型准确率数值（除非用户明示）。
