# Function Description Output Contract

Every P0/P1 `FUN-XXX` identifies purpose, `FEA-XXX`, `ST-XXX`, preconditions, roles/permissions, main flow, and the following distinct rule sets:

- `IX-XXX`: user action/trigger, system response/feedback, applicable page/state, source.
- `BR-XXX`: domain policy, calculation, constraint or state rule.
- `VL-XXX`: input/data validation and user-visible error outcome.
- `AC-XXX`: measurable Given/When/Then acceptance basis.

Each P0 function also defines state changes and exception/failure/retry/rollback/recovery behavior. Field and analytics sections appear only when triggered.
