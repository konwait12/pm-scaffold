# 思考框架（Thinking Framework · L0 轻量版）

L0 轻量档**不做完整七透镜**。仅用轻量三问生成 mini-prd 内容；完整透镜（thinking-core.md §1）由 L1/L2 档使用。

## 轻量三问（L0 必用）

1. **第一性原理**：这次改动改变的可观察结果是什么？（不写实现细节）
2. **影响面**：改了什么入口？哪些角色会看到差异？失败怎么回滚？
3. **对抗性审视**：什么情况下这个改动是错的？后端返回异常/空数据会怎样？

## 升档信号

如果三问暴露出以下任一信号 → **停止生成，返回 intake-routing 升档**：
- 涉及 ≥2 模块或跨端
- 涉及 ≥2 角色或外部角色
- 存在状态机必要（≥2 状态）
- 含合规 / 资金 / PII
- 异常路径 ≥3

完整资格矩阵与硬升级条件见 `src/shared/intake-routing/references/process-tier-routing.md`；评分若用于沟通，只是辅助信号。
