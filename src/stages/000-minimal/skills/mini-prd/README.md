# 轻量事实采集（Mini PRD · L0 档）Skill

L0 轻量档的单一主工作项：一个 skill、一个 mini-prd.md、business_owner 单签。mini-prd 是紧凑事实采集与起草工件；批准后由固定映射生成与 L1/L2 共用章节契约一致的 canonical `003-prd-output/prd.md`。适合 bug 修复 / 文案调整 / 配置开关 / 一处展示调整。

命中任一升档触发线（多模块 / 多角色 / 状态机 / 合规资金 / 大改动）时返回 intake-routing 升档 L1/L2，不硬塞进 L0。

轻量治理：保留单签 ReviewRecord、hash 锚和 audit event；裁掉 preflight / 七透镜 / taxonomy 扫描 / B3 收口表 / issue-record 独立库 / 跨产物上游链。最终 PRD 的章节契约与适用性判定不能裁掉。
