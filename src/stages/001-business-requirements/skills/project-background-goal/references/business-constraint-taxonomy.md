# 业务约束五分类技法参考（Business Constraint Taxonomy）

> 来源吸收：Trae `prd-to-prototype` skill 的「业务约束五分类细分 + 需求来源三段式」，作为 project-background-goal 的可选 to B 落地能力。
> 定位：project-background-goal 产出的 BG-XXX 背景目标文本是权威；本文档提供"把业务约束按五类细分结构化登记"的技法，增强约束可见性。
> 触发：当项目背景涉及合规、时间、预算、组织或历史约束时使用。**按需加载，不设全局闸门**。

## 1. 输入映射（pm-scaffold 语境）

| 外部 skill 输入 | pm-scaffold 对应产物 | 说明 |
|---|---|---|
| 业务约束 | project-background-goal 的 BG-XXX | 五分类登记对象 |

| 来源材料 | 00-input 的 SRC-* | 约束的证据 |
| 角色权限 | user-journey 的角色 | 组织约束依据 |

> **上游未 confirmed，不启动分类**：以 BG-XXX 已确认背景为准；缺失标 `待确认`。

## 2. 业务约束五分类细分（吸收自 prd-to-prototype）

| 类别 | 细分项 | to B 示例 |
|---|---|---|
| **合规约束** | 法规/牌照/数据出境 | 等保三级、《数据安全法》、数据出境合规、金融牌照 |
| **时间约束** | 上线时间/竞品压力 | 季度上线、监管报送截止、竞品 Q3 发布 |
| **预算约束** | 预算限制/席位限制 | 研发预算 50 万、SaaS 席位上限 200 |
| **组织约束** | 需 XX 部门配合/需老板审批 | 需财务部对账配合、需 CTO 审批、跨部门协作 |
| **历史约束** | 之前做过失败/用户投诉过 | 对接老 ERP、存量数据迁移、既有 SLA、之前同类功能下线 |

每类约束须登记细分项 + 具体值 + 证据来源（SRC-*）。

## 3. 需求来源三段式（吸收自 prd-to-prototype）

每条约束/需求须登记来源三段式：

- **来源类型**：用户反馈 / 竞品分析 / 战略规划 / 老板指示 / 数据分析 / 合规要求
- **来源人**：角色 + 部门（脱敏后，如"业务负责人-运营部"）
- **来源场合**：需求评审会 / 用户访谈 / 工单系统 / 老板 1v1 / 战略会

## 4. 工作流程

1. **扫材料**：从 00-input 的 SRC-* 提取约束性陈述。
2. **归类细分**：按 §2 五分类 + 细分项登记；跨类约束标多类；无证据的标 `AI_INFERENCE`。
3. **挂来源**：每条约束按 §3 三段式登记来源类型/来源人/来源场合。
4. **挂范围**：每类约束关联 In/Out/Deferred 的依据。
5. **登记**：在 BG-XXX 约束章节呈现，每条追溯 SRC-*。

## 5. 核心硬规则

1. **约束有据**：每条约束追溯 SRC-*；无证据标 `AI_INFERENCE`，不静默当事实。
2. **细分项必填**：每类约束须登记到细分项（如合规须写"等保三级"而非仅"合规"）；不写"等"省略。
3. **来源三段式齐全**：每条约束须有来源类型+来源人+来源场合；来源人脱敏。
4. **to B 合规优先**：合规约束须显式标注法规/标准名称（如《数据安全法》/等保三级/金融牌照），数据出境须单独标注。
5. **组织约束显式审批层级**：to B 须标注审批流层级与部门边界（如"需 CTO 审批"），不合并为"需领导审批"。
6. **历史约束显式遗留边界**：遗留系统/存量数据须标注接口与迁移边界（如"对接老 ERP 的 XX 接口"）。

## 6. 边界（Do Not）

- 不替业务方定约束值——AI 推断交人工确认，标 `AI_INFERENCE`。
- 不替代 BG-XXX 文本——五分类是登记视图，文本是权威。
- 不展开技术架构（接口协议/数据库迁移脚本，超出 PRD-only）。
- 不省略细分项与来源三段式。

## 7. 质量自检清单

- [ ] 每条约束追溯 SRC-*，无证据标 AI_INFERENCE
- [ ] 每类约束登记到细分项，无"等"省略
- [ ] 每条约束来源三段式齐全（类型+人+场合），来源人脱敏
- [ ] 合规约束标注法规/标准名称，数据出境单独标注（to B）
- [ ] 组织约束标注审批层级与部门边界
- [ ] 历史约束标注遗留系统接口与迁移边界
- [ ] 跨类约束标多类，无遗漏
