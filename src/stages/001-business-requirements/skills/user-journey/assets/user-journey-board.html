DATA数据源与替换指引如何把这份板接到具体产物▸

本板是中性模板，不绑定具体项目。使用时把 DATA 对象（脚本顶部）替换为当前 user-journey.md 的角色 / 阶段 / 节点 / 边 / 形态 / 分类 / 分支 / 空态 / 状态机数据。数据结构（与 skill 主文档矩阵一致）如下：

DATA = {
  meta:  { title, crumb, narrative, motIds: [] },
  stages:  [ { idx, code, name, trig } ... ],          // 6 阶段（顺序）
  roles:   [ { idx, code, who, goal } ... ],           // ≥1 角色
  nodes:   [ { id, r, s, title, behavior, touch, pain, path, ev, form?, cat? } ... ],  // r/s 为 roles/stages idx
  edges:   [ [from, to] or [from, to, "back"] ... ],  // "back" 画虚线
  forms:   [ { id, cat:"ext|int", name, rule, nodes } ... ],  // 可选，护栏 2
  categories: [ { dim, hbg, rtw } ... ],              // 可选，护栏 1
  branches:   [ { dim, value, affects, given, status } ... ], // 可选，护栏 3
  emptyStates: [ { state, list, entry, menu, status } ... ],  // 可选，护栏 3
  states:     [ { id, name, type:"initial|normal|loopback|final", desc, trig } ... ],
  stateEdges: [ { from, to, label } ... ]
}

路径类型 path 取值：normal | alternative | exception | failure | handoff | recovery（与 skill 一致）。MOT 节点在 meta.motIds 列表声明（按节点 id 串）。

边界：本板不呈现页面原型/功能清单/技术实现；只读、零网络、只补已知节点；扩展性附录（护栏 1-3、状态机）按需填入，未填时折叠显示为占位。
