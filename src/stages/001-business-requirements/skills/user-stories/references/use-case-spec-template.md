# UML 用例规格技法参考（Use Case Spec Template）

> 来源吸收：Trae `prd-generator` skill 的「UML 用例驱动方法论 + 用例规格模板 + 时序图模板 + 常用意图类型表」，经 to B 适配后作为 user-stories 的可选落地能力。
> 定位：user-stories 产出的 ST-XXX 故事文本是权威；本文档提供"把用户故事结构化为 UML 用例规格"的技法，增强参与者与事件流的可追溯性。
> 触发：当需求涉及多参与者、用例关系（include/extend）或需规格化交付时使用。**按需加载，不设全局闸门**。

## 1. 输入映射（pm-scaffold 语境）

| 外部 skill 输入 | pm-scaffold 对应产物 | 说明 |
|---|---|---|
| 用户故事 | user-stories 的 ST-XXX | 用例的参与者与价值 |
| 用户旅程 | user-journey 的 UJ-XXX | 用例的场景路径 |
| 功能清单 | feature-list 的 FEA-XXX | 用例的功能边界 |
| 业务规则 | business-rules 的 BR-XXX | 用例规格的业务规则 |
| 校验字段 | validation-rules 的 VL-XXX | 用例的数据说明表 |

> **上游未 confirmed，不启动用例规格**：以 ST-XXX 已确认故事为准；缺失标 `待确认`。

## 2. 用例规格模板（吸收自 prd-generator）

每个用例（UC-XX，对齐 ST-XXX）按以下结构：

```markdown
### UC-XX [用例名称]

| 项目 | 内容 |
|------|------|
| 用例编号 | UC-XX（对齐 ST-XXX） |
| 用例名称 | [用例名称] |
| 参与者 | [参与者列表，追溯 user-journey 角色] |
| 前置条件 | [触发前必须成立，追溯 RBAC/权限] |
| 后置条件 | [完成后系统状态，追溯 STATE-XXX] |
| 优先级 | 高/中/低（MoSCoW 对齐） |

#### 基本事件流
1. [步骤1]
2. [步骤2]
3. [步骤3]（每步追溯 functional-flow 节点）

#### 备选事件流
1a. [异常1]：系统[处理方式]（追溯 EX-XXX）
2a. [异常2]：系统[处理方式]

#### 业务规则
1. [规则1]（追溯 BR-XXX）
2. [规则2]

#### 数据说明表
| 字段名 | 字段中文名 | 数据类型 | 取值范围 | 是否必填 | 备注说明 |
|--------|------------|----------|----------|----------|----------|
| field_name | 字段中文名 | VARCHAR(100) | 任意字符串 | 是/否 | 字段说明（追溯 VL-XXX） |
```

## 5. 工作流程

1. **识别参与者**：从 user-journey 角色提取，按 RBAC 标注权限差异；系统/定时任务/外部集成作为特殊参与者。
2. **梳理用例**：每个 ST-XXX 映射一个 UC-XX；含 include/extend 关系显式标注。
3. **写规格**：按模板填写，基本流追溯 functional-flow，备选流追溯 EX-XXX，规则追溯 BR-XXX。
4. **挂数据**：数据说明表字段追溯 VL-XXX，类型对齐数据字典。
5. **画时序图**：多角色流转用时序图描述（按 §3 模板）。
6. **标意图**：数据分析类用例标注意图类型（按 §4 表）。

## 6. 核心硬规则

1. **用例不发明功能**：UC-XX 必须对齐已确认 ST-XXX / FEA-XXX，不得新增流程外用例。
2. **备选流必须覆盖异常**：每个用例至少列 1 条备选流，追溯 EX-XXX；无 EX-XXX 则标 `待确认`。
3. **数据说明不空挂**：每个字段追溯 VL-XXX；无上游字段标 `待确认`，不自行定义类型。
4. **to B 权限显式**：参与者须标注角色权限层级（追溯 RBAC）；多租户用例标注租户边界。
5. **系统参与者标注触发条件**：定时任务/外部集成/自动流转作为特殊参与者时，标注触发条件。

## 7. 边界（Do Not）

- 不绘制用例图替代文本（图是辅助，规格表是权威）。
- 不替业务方决定优先级——以 feature-list 的 MoSCoW 为准。
- 不设计接口/数据库表结构（超出 PRD-only）。
- 不把交互微细节塞入基本流（属 interaction-rules）。

## 8. 质量自检清单

- [ ] 每个 UC-XX 对齐 ST-XXX，无发明用例
- [ ] 参与者标注 RBAC 权限层级（to B），系统参与者标注触发条件
- [ ] 基本流每步追溯 functional-flow 节点
- [ ] 备选流至少 1 条，追溯 EX-XXX
- [ ] 业务规则追溯 BR-XXX
- [ ] 数据说明字段追溯 VL-XXX，类型对齐数据字典
- [ ] 多角色流转有时序图
- [ ] 数据分析类用例标注意图类型
- [ ] 无接口/数据库越界内容
