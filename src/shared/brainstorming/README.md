# Brainstorming

Use when sparse input, missing roles/scenes, or material alternatives require divergent exploration. It is an internal mode, not a stage or independently confirmed artifact.

Start from a stated question and evidence boundary; generate candidates from role, lifecycle, system, failure, constraint and reverse perspectives; cluster and deduplicate; label every candidate as AI inference; then ask the responsible human to include, exclude, defer or investigate. Only included candidates may flow into a formal artifact.

Workflow: state the stuck point or vague input → diverge across the required lenses → present labeled candidates → pause for human include/exclude/defer/investigate decisions → converge selected items → return to the current Work Item. Use `src/templates/others/brainstorming-output.md` when a persistent record is needed.
